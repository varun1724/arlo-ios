# Purpose
Use this skill when implementing voice interaction, speech entry, App Intents, or Siri Shortcut flows.

# Product behavior
Voice is the primary control surface.
The user should be able to:
- ask what to do now
- log completed activity
- adjust the day
- ask for food ideas
- ask for learning briefs
- ask for startup ideas

# MVP rules
- tap-to-talk is enough for MVP
- support concise transcript display
- support short response rendering
- App Shortcut path should be realistic and limited to the highest-value actions

# Candidate App Shortcuts
Limit to a small set:
- Talk to Arlo
- Start my day
- Log workout complete
- Play today’s brief

# Interaction style
Responses should be:
- short
- helpful
- slightly conversational
- never long and rambling

# UI constraints
- The voice screen should feel focused, not like a full chat app
- Keep transcript and response presentation compact
- Make the listening state obvious
