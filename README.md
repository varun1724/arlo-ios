# Arlo

Arlo is a voice-first, notification-driven iOS personal operator built with SwiftUI.

## What Arlo does
Arlo helps the user:
- stay on top of workouts, meals, steps, and posture
- receive useful notifications throughout the day
- talk naturally to update plans and get recommendations
- get lightweight tech/news learning and startup ideas
- reduce passive phone use by surfacing the next right thing

## MVP focus
- onboarding
- Today screen
- task/routine model
- daily planner
- notifications with quick actions
- voice input
- gym geofence
- widget
- Siri Shortcut / App Shortcut support
- lightweight memory

## Product principles
- reduce decisions
- minimize screen time
- make the next action obvious
- stay calm and native
- avoid generic AI app aesthetics

## Suggested workflow
- Keep the repo open in Xcode for simulator/build/previews

## AI Backend Direction

Arlo is planned as a voice-first app with a real backend intelligence layer.

The backend is intended to support:
- user memory
- routines and goals
- daily planning
- voice intent parsing
- learning and adaptation
- brief generation
- startup idea generation

For MVP, Arlo will use a practical, scoped backend rather than a giant autonomous agent system.

The backend should start by supporting:
- structured user profile
- routines and task generation
- task persistence
- voice-driven updates
- lightweight memory
- planner recalculation

Long-term, this backend can evolve into a platform for multiple domain operators such as:
- health
- learning
- ideas/building
- career
- opportunities
- side hustles
